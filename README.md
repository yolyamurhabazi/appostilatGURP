# Apostolat GURP

Site Next.js pour l'apostolat du GURP à l'orphelinat de Bagira, prévu le 6 décembre 2026.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000). Pour vérifier la version de production :

```bash
npm run build
```

## Fonctionnement

- Choix d'une catégorie de don : fournitures scolaires, vivres, non-vivres ou somme d'argent.
- Récapitulatif dynamique avec nom, téléphone et détails facultatifs.
- Message WhatsApp prérempli pour chacun des trois organisateurs, ou appel direct.
- Mise en page adaptable aux écrans d'ordinateur et de téléphone, avec animations respectant la préférence de mouvement réduit.

Les deux photos utilisées sont des **illustrations générées par IA** ; elles ne représentent pas une visite réelle de l'orphelinat.

Site en ligne : [appostilatgurp.vercel.app](https://appostilatgurp.vercel.app).
